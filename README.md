Este projeto tem como objetivo praticar o uso das estruturas de repetição for, while e do-while por meio da simulação de movimentos de peças de xadrez. O programa em C mostra, passo a passo, os deslocamentos da Torre, Bispo e Rainha, imprimindo no console a direção de cada movimento.


Torre: move-se 5 casas para a direita (usando for);


Bispo: move-se 5 casas na diagonal para cima e à direita (usando while);


Rainha: move-se 8 casas para a esquerda (usando do-while).


O código é simples, organizado e comentado, destacando a lógica de cada estrutura de repetição e demonstrando, de forma prática, a movimentação das peças no tabuleiro.# desafio-xadrez
